# Decisiones que deben tomarse antes de desarrollar (sección 30 del documento base)

Ninguna investigación técnica puede resolver esto por el equipo — son decisiones
institucionales/de negocio. Checklist:

- [ ] Entidad propietaria y responsable del tratamiento de datos.
- [ ] Alcance territorial del piloto y fenómeno inicial de prueba.
- [ ] Instrumentos oficiales exactos que se mapearán en la versión 1 (¿FR-1703-SMD-08 o -09?
      confirmar con la UNGRD cuál es el vigente exacto — ver `research/HALLAZGOS.md`).
- [ ] Perfiles profesionales y procedimiento de verificación (¿cómo se valida que alguien
      es ingeniero civil/arquitecto habilitado antes de darle el rol "profesional"?).
- [ ] Umbrales para clasificaciones preliminares y quién los aprueba.
- [ ] Mapa base y capas oficiales autorizadas.
- [ ] Política de almacenamiento de imágenes/video y retención.
- [ ] Modelo de hosting: nube, centro de datos público o híbrido.
- [ ] Nivel de interoperabilidad requerido con UNGRD, municipios y demás actores.
- [ ] Licenciamiento del software y política de propiedad intelectual.
- [ ] **Nombre comercial SIGERIA**: pendiente búsqueda formal de antecedentes marcarios
      ante la SIC y verificación de dominios/tiendas de aplicaciones antes de cualquier
      registro o contratación (advertencia explícita del documento base).

Ver también `research/HALLAZGOS.md` §6 para recomendaciones técnicas que sí se pudieron
resolver en esta fase (reutilizar XLSForm, pilotar con QField, etc.).
